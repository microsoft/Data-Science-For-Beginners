# Dangerous Liaisons ဒေတာမြင်ကွင်းပရောဂျက်

စတင်အသုံးပြုရန်အတွက် NPM နှင့် Node **>=20.0.0** သင့်စက်တွင် တင်ထားပြီး ပြေးနေမှုရှိစေရန် သေချာစေရန်လိုအပ်သည်။ စနစ်ပေါင်းစည်းမှုများ (npm install) နောက်တစ်ဆင့် ပရောဂျက်ကို ဒေသစနစ်ပေါ်တွင် ပြေးရန် (npm run serve) လုပ်ဆောင်ပါ။

## ပရောဂျက်စတင်ခြင်း
```
npm install
```

### ဖန်တီးခြင်းနှင့် ဖွံ့ဖြိုးမှုအတွက် အပူပြန်ဖွင့်ချက်များ
```
npm run serve
```

### ထုတ်လုပ်ရေးအတွက် ဖိုင်များကို စုစည်းခြင်းနှင့် သေးငယ်စေခြင်း
```
npm run build
```

### ဖိုင်စစ်ဆေးခြင်းနှင့် ပြင်ဆင်ခြင်း
```
npm run lint
```

### ပြင်ဆင်မှုများကို ညှိနှိုင်းခြင်း
ကြည့်ရှုရန် [Configuration Reference](https://cli.vuejs.org/config/)။
