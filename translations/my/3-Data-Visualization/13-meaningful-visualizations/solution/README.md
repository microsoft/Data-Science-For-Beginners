# Dangerous Liaisons ဒေတာဗွါချွေးရှင်းပရောဂျက်

စတင်ရန်အတွက်၊ သင့်စက်ပေါ်တွင် NPM နှင့် Node **>=20.0.0** တိုက်ရိုက်ပေါက်ထားကြောင်းအာမခံရပါမည်။ အခြေခံလိုအပ်ချက်များ (npm install) ကိုထည့်သွင်းပြီးနောက် ပရောဂျက်ကို ဒေသန္တရ (npm run serve) ဖြင့် ချပြပါ။

## ပရောဂျက်တပ်ဆင်မှု
```
npm install
```

### ဖွံ့ဖြိုးတိုးတက်မှုအတွက် ကုဒ်များကို တည်ဆောက်ပြီး အပူမြင့်ပြန်လည်သွင်းပါ
```
npm run serve
```

### ထုတ်လုပ်မှုအတွက် ကုဒ်များကို တည်ဆောက်ပြီး အနိမ့်ဆုံးဖြင့်ပြုလုပ်ပါ
```
npm run build
```

### ဖိုင်များအား ဖော်ထုတ် ပြင်ဆင်ပါ
```
npm run lint
```

### ပြင်ဆင်မှုများကို တိုးချဲ့ချိန်ညှိပါ
See [Configuration Reference](https://cli.vuejs.org/config/).
