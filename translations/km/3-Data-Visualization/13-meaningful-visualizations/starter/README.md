# គម្រោងការពិព៌ណទិន្នន័យ Dangerous Liaisons

ដើម្បីចាប់ផ្តើម អ្នកត្រូវ​ប្រាកដថា​មាន NPM និង Node **>=20.0.0** រត់​លើម៉ាស៊ីន​របស់អ្នក។ តំឡើងការ​អាស្រ័យ​គ្នា (npm install) ហើយបន្ទាប់​មក​រត់​គម្រោង​នៅ​តំបន់​ផ្ទាល់ (npm run serve)៖

## ការតំឡើងគម្រោង
```
npm install
```

### ប្រមូលកូដ និងបញ្ចេញឡើងវិញសម្រាប់ការអភិវឌ្ឍ
```
npm run serve
```

### ប្រមូលកូដ និងកាត់បន្ថយសម្រាប់ផលិតកម្ម
```
npm run build
```

### ពិនិត្យ និងជួសជុលឯកសារ
```
npm run lint
```

### ប្តូរ​ការកំណត់​នៅតាមចំណេញរបស់អ្នក
មើល [Configuration Reference](https://cli.vuejs.org/config/)។
