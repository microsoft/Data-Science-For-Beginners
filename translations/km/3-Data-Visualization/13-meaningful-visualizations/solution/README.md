# គម្រោងបង្ហាញទិន្នន័យ Dangerous Liaisons

ដើម្បីចាប់ផ្តើម អ្នកត្រូវប្រាកដថា អ្នកមាន NPM និង Node **>=20.0.0** រត់នៅលើម៉ាស៊ីនរបស់អ្នក។ តំឡើងការពឹងផ្អែក (npm install) បន្ទាប់មករត់គម្រោងក្នុងរបៀបក្នុងមូលដ្ឋាន (npm run serve):

## ការកំណត់គម្រោង
```
npm install
```

### បកកូដ និងបញ្ចូលឡើងវិញសម្រាប់ការអភិវឌ្ឍ
```
npm run serve
```

### បកកូដ និងបង្រួមសម្រាប់ផលិតកម្ម
```
npm run build
```

### ពិនិត្យ និងជួសជុលឯកសារ
```
npm run lint
```

### កំណត់រចនាសម្ព័ន្ធបែបផ្ទាល់ខ្លួន
សូមមើល [Configuration Reference](https://cli.vuejs.org/config/)។
