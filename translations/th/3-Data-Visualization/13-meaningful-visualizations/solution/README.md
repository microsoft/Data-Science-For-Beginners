# โครงการ visualization ข้อมูล Dangerous Liaisons

ในการเริ่มต้น คุณต้องแน่ใจว่าคุณมี NPM และ Node **>=20.0.0** ทำงานบนเครื่องของคุณ ติดตั้ง dependencies (npm install) แล้วรันโปรเจกต์ในเครื่อง (npm run serve):

## การตั้งค่าโครงการ
```
npm install
```

### คอมไพล์และรีโหลดอัตโนมัติสำหรับการพัฒนา
```
npm run serve
```

### คอมไพล์และบีบอัดสำหรับการผลิต
```
npm run build
```

### ตรวจสอบและแก้ไขไฟล์
```
npm run lint
```

### ปรับแต่งการตั้งค่า
ดูที่ [Configuration Reference](https://cli.vuejs.org/config/).
