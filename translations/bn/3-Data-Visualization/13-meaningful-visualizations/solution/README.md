# ডেঞ্জারাস লিয়াজোনস ডেটা ভিজ্যুয়ালাইজেশন প্রকল্প

শুরু করতে, আপনাকে নিশ্চিত করতে হবে যে আপনার মেশিনে NPM এবং Node **>=20.0.0** চলমান আছে। নির্ভরশীলতাগুলো ইনস্টল করুন (npm install) এবং তারপর প্রকল্পটি লোকালি চালান (npm run serve):

## প্রকল্প সেটআপ
```
npm install
```

### বিকাশের জন্য কম্পাইল এবং হট-রিলোড করে
```
npm run serve
```

### উৎপাদনের জন্য কম্পাইল এবং মিনিফাই করে
```
npm run build
```

### লিন্ট করে এবং ফাইলগুলো ঠিক করে
```
npm run lint
```

### কনফিগারেশন কাস্টোমাইজ করুন
দেখুন [Configuration Reference](https://cli.vuejs.org/config/)।
