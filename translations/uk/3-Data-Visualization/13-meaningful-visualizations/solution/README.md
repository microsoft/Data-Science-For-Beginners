# Проєкт візуалізації даних Dangerous Liaisons

Щоб почати, вам потрібно переконатися, що у вас на комп’ютері встановлені NPM і Node **>=20.0.0**. Встановіть залежності (npm install), а потім запустіть проєкт локально (npm run serve):

## Налаштування проєкту
```
npm install
```

### Компільовано і гаряче перезавантаження для розробки
```
npm run serve
```

### Компільовано і мінімізовано для продакшена
```
npm run build
```

### Лінтування та виправлення файлів
```
npm run lint
```

### Налаштування конфігурації
Дивіться [Configuration Reference](https://cli.vuejs.org/config/).
