# 危險關係資料視覺化專案

要開始使用，您需要確保您的機器上運行的是 NPM 和 Node **>=20.0.0**。安裝相依套件（npm install），然後在本機執行專案（npm run serve）：

## 專案設定
```
npm install
```

### 開發時編譯及熱重載
```
npm run serve
```

### 生產環境編譯及壓縮
```
npm run build
```

### Lint 檢查及修正檔案
```
npm run lint
```

### 自訂配置
請參閱 [配置參考](https://cli.vuejs.org/config/)。
