# डेंजरस लायज़न्स डेटा विज़ुअलाइज़ेशन प्रोजेक्ट

शुरू करने के लिए, आपको यह सुनिश्चित करना होगा कि आपके मशीन पर NPM और Node **>=20.0.0** चल रहा हो। निर्भरताएं इंस्टॉल करें (npm install) और फिर प्रोजेक्ट को लोकल रूप से चलाएं (npm run serve):

## प्रोजेक्ट सेटअप
```
npm install
```

### विकास के लिए कंपाइल और हॉट-रिलोड
```
npm run serve
```

### उत्पादन के लिए कंपाइल और मिनिफाई
```
npm run build
```

### लिंट करता है और फाइलें ठीक करता है
```
npm run lint
```

### कॉन्फ़िगरेशन अनुकूलित करें
देखें [Configuration Reference](https://cli.vuejs.org/config/)।
