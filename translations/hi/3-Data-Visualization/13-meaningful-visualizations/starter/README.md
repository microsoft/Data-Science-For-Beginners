# खतरनाक संबंध डेटा विज़ुअलाइज़ेशन प्रोजेक्ट

शुरू करने के लिए, आपको यह सुनिश्चित करना होगा कि आपके सिस्टम पर NPM और Node **>=20.0.0** चल रहे हों। निर्भरताएँ इंस्टॉल करें (npm install) और फिर प्रोजेक्ट को स्थानीय रूप से चलाएं (npm run serve):

## प्रोजेक्ट सेटअप
```
npm install
```

### विकास के लिए संकलन और हॉट-रिलोड
```
npm run serve
```

### उत्पादन के लिए संकलन और मिनिफ़ाई
```
npm run build
```

### फ़ाइलों की लिंटिंग और सुधार
```
npm run lint
```

### कॉन्फ़िगरेशन कस्टमाइज़ करें
देखें [Configuration Reference](https://cli.vuejs.org/config/)।
