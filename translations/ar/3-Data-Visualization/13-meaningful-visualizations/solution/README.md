# مشروع تصور بيانات العلاقات الخطرة

للبدء، تحتاج إلى التأكد من أن لديك NPM و Node **>=20.0.0** يعملان على جهازك. قم بتثبيت التبعيات (npm install) ثم شغّل المشروع محليًا (npm run serve):

## إعداد المشروع
```
npm install
```

### تجميع وإعادة تحميل ساخنة للتطوير
```
npm run serve
```

### تجميع وتصغير للإنتاج
```
npm run build
```

### التحقق من التنسيق وإصلاح الملفات
```
npm run lint
```

### تخصيص التهيئة
انظر [Configuration Reference](https://cli.vuejs.org/config/).
