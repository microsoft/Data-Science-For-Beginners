# مشروع تصور بيانات العلاقات الخطيرة

للبدء، عليك التأكد من أن لديك NPM و Node **>=20.0.0** يعملان على جهازك. قم بتثبيت التبعيات (npm install) ثم شغّل المشروع محليًا (npm run serve):

## إعداد المشروع
```
npm install
```

### يجمّع ويحمّل تلقائيًا أثناء التطوير
```
npm run serve
```

### يجمّع ويقلل الحجم للإنتاج
```
npm run build
```

### يفحص ويصلح الملفات
```
npm run lint
```

### تخصيص الإعدادات
انظر [مرجع التكوين](https://cli.vuejs.org/config/).
