# Ohtlike sidemete andmete visualiseerimise projekt

Alustamiseks peab sul olema masinas paigaldatud NPM ja Node versiooniga **>=20.0.0**. Paigalda sõltuvused (npm install) ja seejärel käivita projekt lokaalselt (npm run serve):

## Projekti seadistamine
```
npm install
```

### Koostab ja laadib arendamiseks kiiresti uuesti
```
npm run serve
```

### Koostab ja minimeerib tootmiseks
```
npm run build
```

### Kontrollib ja parandab faile
```
npm run lint
```

### Kohanda seadistust
Vaata [Konfiguratsiooni viidet](https://cli.vuejs.org/config/).
