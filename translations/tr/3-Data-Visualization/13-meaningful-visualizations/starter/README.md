# Tehlikeli Bağlantılar veri görselleştirme projesi

Başlamak için, makinenizde NPM ve Node **>=20.0.0** yüklü ve çalışıyor olmalıdır. Bağımlılıkları yükleyin (npm install) ve ardından projeyi yerel olarak çalıştırın (npm run serve):

## Proje kurulumu
```
npm install
```

### Geliştirme için derler ve sıcak yeniden yükleme yapar
```
npm run serve
```

### Üretim için derler ve küçültür
```
npm run build
```

### Dosyaları denetler ve düzeltir
```
npm run lint
```

### Yapılandırmayı özelleştir
Bakınız [Configuration Reference](https://cli.vuejs.org/config/).
