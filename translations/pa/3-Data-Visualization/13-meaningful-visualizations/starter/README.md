# Dangerous Liaisons ਡੇਟਾ ਵਿਜ਼ੁਅਲਾਈਜੇਸ਼ਨ ਪ੍ਰੋਜੈਕਟ

ਸ਼ੁਰੂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਯਕੀਨੀ ਬਣਾਣਾ ਚਾਹੀਦਾ ਹੈ ਕਿ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ 'ਤੇ NPM ਅਤੇ Node **>=20.0.0** ਚਲ ਰਹੇ ਹਨ। ਡਿਪੈਂਡੇਨਸੀਜ਼ ਨੂੰ ਇੰਸਟਾਲ ਕਰੋ (npm install) ਅਤੇ ਫਿਰ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਲੋਕਲ ਤੌਰ 'ਤੇ ਚਲਾਓ (npm run serve):

## ਪ੍ਰੋਜੈਕਟ ਸੈੱਟਅੱਪ
```
npm install
```

### ਡਿਵੈਲਪਮੈਂਟ ਲਈ ਕੰਪਾਇਲ ਅਤੇ ਹੌਟ-ਰੀਲੋਡ ਕਰਦਾ ਹੈ
```
npm run serve
```

### ਪ੍ਰੋਡਕਸ਼ਨ ਲਈ ਕੰਪਾਇਲ ਅਤੇ ਸੈਡ ਕਰਦਾ ਹੈ
```
npm run build
```

### ਲਿੰਟ ਕਰਦਾ ਹੈ ਅਤੇ ਫਾਈਲਾਂ ਠੀਕ ਕਰਦਾ ਹੈ
```
npm run lint
```

### ਕਨਫਿਗਰੇਸ਼ਨ ਨੂੰ ਕਸਟਮਾਈਜ਼ ਕਰੋ
ਦੇਖੋ [Configuration Reference](https://cli.vuejs.org/config/)।
