# ਡੇੰਜਰਸ ਲਿਆਇਜ਼ਨਜ਼ ਡਾਟਾ ਵਿਜ਼ੁਅਲਾਈਜੇਸ਼ਨ ਪ੍ਰੋਜੈਕਟ

ਸ਼ੁਰੂ ਕਰਨ ਲਈ, ਤੁਹਾਨੂੰ ਇਹ ਯਕੀਨੀ ਬਣਾਉਣਾ ਚਾਹੀਦਾ ਹੈ ਕਿ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ 'ਤੇ NPM ਅਤੇ Node **>=20.0.0** ਚੱਲ ਰਹੇ ਹਨ। ਡੀਪੈਂਡੈਂਸੀਜ਼ ਇੰਸਟਾਲ ਕਰੋ (npm install) ਅਤੇ ਫਿਰ ਪ੍ਰੋਜੈਕਟ ਨੂੰ ਲੋਕਲ ਹੋ ਕੇ ਰਨ ਕਰੋ (npm run serve):

## ਪ੍ਰੋਜੈਕਟ ਸੈਟਅੱਪ
```
npm install
```

### ਵਿਕਾਸ ਲਈ ਕੰਪਾਈਲ ਅਤੇ ਹੌਟ-ਰੀਲੋਡ ਕਰਦਾ ਹੈ
```
npm run serve
```

### ਉਤਪਾਦਨ ਲਈ ਕੰਪਾਈਲ ਅਤੇ ਮਿੰਨੀਫਾਈ ਕਰਦਾ ਹੈ
```
npm run build
```

### ਲਿੰਟ ਅਤੇ ਫਾਇਲਾਂ ਨੂੰ ਠੀਕ ਕਰਦਾ ਹੈ
```
npm run lint
```

### ਸੰਰਚਨਾ ਨੂੰ ਕਸਟਮਾਈਜ਼ ਕਰੋ
ਦੇਖੋ [Configuration Reference](https://cli.vuejs.org/config/)।
