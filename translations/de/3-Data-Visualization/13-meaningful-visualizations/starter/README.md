# Dangerous Liaisons Datenvisualisierungsprojekt

Um zu starten, müssen Sie sicherstellen, dass NPM und Node **>=20.0.0** auf Ihrem Computer laufen. Installieren Sie die Abhängigkeiten (npm install) und führen Sie dann das Projekt lokal aus (npm run serve):

## Projekteinstellungen
```
npm install
```

### Kompiliert und lädt für die Entwicklung automatisch nach
```
npm run serve
```

### Kompiliert und minimiert für die Produktion
```
npm run build
```

### Prüft und behebt Dateien
```
npm run lint
```

### Konfiguration anpassen
Siehe [Configuration Reference](https://cli.vuejs.org/config/).
