# Pavojingų ryšių duomenų vizualizavimo projektas

Norėdami pradėti, turite įsitikinti, kad jūsų kompiuteryje veikia NPM ir Node **>=20.0.0**. Įdiekite priklausomybes (npm install), tada paleiskite projektą lokaliai (npm run serve):

## Projekto nustatymas
```
npm install
```

### Kompiliuoja ir karštai perkrauna kūrimui
```
npm run serve
```

### Kompiliuoja ir minimalizuoja produkcijai
```
npm run build
```

### Tikrina ir taiso failus
```
npm run lint
```

### Konfigūracijos pritaikymas
Žr. [Configuration Reference](https://cli.vuejs.org/config/).
