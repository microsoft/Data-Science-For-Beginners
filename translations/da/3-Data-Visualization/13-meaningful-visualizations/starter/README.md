# Dangerous Liaisons datavisualiseringsprojekt

For at komme i gang skal du sikre, at du har NPM og Node **>=20.0.0** kørende på din maskine. Installer afhængighederne (npm install) og kør derefter projektet lokalt (npm run serve):

## Projektopsætning
```
npm install
```

### Kompilerer og genindlæser til udvikling
```
npm run serve
```

### Kompilerer og minificerer til produktion
```
npm run build
```

### Linter og retter filer
```
npm run lint
```

### Tilpas konfiguration
Se [Configuration Reference](https://cli.vuejs.org/config/).
