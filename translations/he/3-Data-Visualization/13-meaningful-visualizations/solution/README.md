# פרויקט ויזואליזציית נתונים של Dangerous Liaisons

כדי להתחיל, עליך לוודא שיש לך NPM ו-Node **>=20.0.0** פועלים במחשב שלך. התקן את התלויות (npm install) ואז הרץ את הפרויקט מקומית (npm run serve):

## הגדרת הפרויקט
```
npm install
```

### קומפילציה וטעינה מחדש מהירה במהלך פיתוח
```
npm run serve
```

### קומפילציה ומזעור לייצור
```
npm run build
```

### בדיקה ותיקון קבצים
```
npm run lint
```

### התאמת תצורה
ראה [Configuration Reference](https://cli.vuejs.org/config/).
