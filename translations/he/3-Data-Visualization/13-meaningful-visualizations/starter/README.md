# פרויקט ויזואליזציית נתונים קשרים מסוכנים

כדי להתחיל, יש לוודא שיש לכם את NPM ו-Node **>=20.0.0** מותקנים ופועלים על המחשב שלכם. התקינו את התלויות (npm install) ולאחר מכן הריצו את הפרויקט מקומית (npm run serve):

## הגדרת הפרויקט
```
npm install
```

### מקמפל ומטען חם עבור פיתוח
```
npm run serve
```

### מקמפל וממזער עבור הפקה
```
npm run build
```

### בודק ומתקן קבצים
```
npm run lint
```

### התאם אישית את ההגדרות
עיין ב-[Configuration Reference](https://cli.vuejs.org/config/).
