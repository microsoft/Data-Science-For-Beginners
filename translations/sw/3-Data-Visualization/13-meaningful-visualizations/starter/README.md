# Mradi wa uakisi data wa Dangerous Liaisons

Ili kuanza, unahitaji kuhakikisha kwamba una NPM na Node **>=20.0.0** zikiendesha kwenye mashine yako. Sakinisha utegemezi (npm install) kisha endesha mradi ndani ya eneo lako (npm run serve):

## Usanidi wa mradi
```
npm install
```

### Hukuakusanya na kupasha moto kwa ajili ya maendeleo
```
npm run serve
```

### Hukuakusanya na kupunguza kwa ajili ya uzalishaji
```
npm run build
```

### Hufanya ukaguzi wa msimbo na kurekebisha faili
```
npm run lint
```

### Rekebisha usanidi
Tazama [Configuration Reference](https://cli.vuejs.org/config/).
