# Mradi wa uonyesho wa data wa Dangerous Liaisons

Ili kuanza, unahitaji kuhakikisha kuwa una NPM na Node **>=20.0.0** vikifanye kazi kwenye mashine yako. Sakinisha utegemezi (npm install) kisha endesha mradi kwa ndani ya mashine (npm run serve):

## Usanidi wa Mradi
```
npm install
```

### Hukusanya na kuendeleza kwa maendeleo
```
npm run serve
```

### Hukusanya na kupunguza kwa uzalishaji
```
npm run build
```

### Hukagua na kurekebisha faili
```
npm run lint
```

### Binafsisha usanidi
Tazama [Marejeleo ya Usanidi](https://cli.vuejs.org/config/).
