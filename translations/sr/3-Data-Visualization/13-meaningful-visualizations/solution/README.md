# Пројекат визуализације података Џенерал Лијаизонс

Да бисте почели, морате да обезбедите да имате НПМ и Ноде **>=20.0.0** који раде на вашем рачунару. Инсталирајте зависности (npm install) и затим покрените пројекат локално (npm run serve):

## Подешавање пројекта
```
npm install
```

### Компилација и хотрелоад током развоја
```
npm run serve
```

### Компилација и минификовање за продукцију
```
npm run build
```

### Проверa и исправка датотека
```
npm run lint
```

### Прилагођавање конфигурације
Погледајте [Configuration Reference](https://cli.vuejs.org/config/).
