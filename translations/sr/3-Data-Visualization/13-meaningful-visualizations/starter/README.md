# Пројекат визуализације података Dangerous Liaisons

Да бисте почели, потребно је да обезбедите да имате NPM и Node **>=20.0.0** покренуте на свом рачунару. Инсталирајте зависности (npm install) и затим покрените пројекат локално (npm run serve):

## Постављање пројекта
```
npm install
```

### Компилација и хотрелоад за развој
```
npm run serve
```

### Компилација и минифицирање за продукцију
```
npm run build
```

### Линтовање и поправка фајлова
```
npm run lint
```

### Прилагођавање конфигурације
Погледајте [Configuration Reference](https://cli.vuejs.org/config/).
