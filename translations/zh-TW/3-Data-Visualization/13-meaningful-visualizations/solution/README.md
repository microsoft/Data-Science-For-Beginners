# 危險關係數據視覺化專案

要開始，您需要確保機器上執行的 NPM 和 Node **>=20.0.0**。安裝相依套件（npm install）然後本地執行專案（npm run serve）：

## 專案設置
```
npm install
```

### 編譯並提供開發熱重新載入
```
npm run serve
```

### 編譯並為生產環境壓縮
```
npm run build
```

### 進行程式碼檢查並修正檔案
```
npm run lint
```

### 自訂設定
請參考 [設定參考](https://cli.vuejs.org/config/)。
