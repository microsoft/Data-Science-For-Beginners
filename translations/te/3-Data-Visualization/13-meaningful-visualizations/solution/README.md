# డేంజరస్ లియిలేషన్స్ డేటా విజువలైజేషన్ ప్రాజెక్ట్

ప్రారంభించడానికి, మీ మిషన్‌లో NPM మరియు Node **>=20.0.0** రన్ అయి ఉన్నదని నిర్ధారించుకోవాలి. డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి (npm install) మరియు ఆ తర్వాత ప్రాజెక్ట్‌ను లోకల్‌గా రన్ చేయండి (npm run serve):

## ప్రాజెక్ట్ సెట్ అప్
```
npm install
```

### అభివృద్ధి కోసం కంపైల్ చేసి హాట్-రీలోడ్ చేస్తుంది
```
npm run serve
```

### ఉత్పత్తి కోసం కంపైల్ చేసి మినిఫై చేస్తుంది
```
npm run build
```

### లింట్ చేసి ఫైళ్లు సరిచేస్తుంది
```
npm run lint
```

### కాన్ఫిగరేషన్‌ను అనుకూలీకరించండి
చూడండి [Configuration Reference](https://cli.vuejs.org/config/).
