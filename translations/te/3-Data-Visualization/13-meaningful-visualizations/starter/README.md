# డేంజరస్ లియెజన్ డేటా విజువలైజేషన్ ప్రాజెక్ట్

ప్రారంభించడానికి, మీ యంత్రంపై NPM మరియు Node **>=20.0.0** ఉండాలని నిర్ధారించుకోవాలి. డిపెండెన్సీలను ఇన్స్టాల్ చేయండి (npm install) మరియు తర్వాత ప్రాజెక్ట్ను స్థానికంగా రన్ చేయండి (npm run serve):

## ప్రాజెక్ట్ సెటప్
```
npm install
```

### అభివృద్ధికై కంపైల్ చేసి హాట్-రీలోడ్ చేస్తుంది
```
npm run serve
```

### ఉత్పత్తికై కంపైల్ చేసి మినిఫై చేస్తుంది
```
npm run build
```

### లింట్ చేసి ఫైళ్లను సరిచేస్తుంది
```
npm run lint
```

### కాన్ఫిగరేషన్‌ను కస్టమైజ్ చేయండి
చూడండి [Configuration Reference](https://cli.vuejs.org/config/).
