# Dangerous Liaisons datavisualiseringsprojekt

För att komma igång måste du säkerställa att du har NPM och Node **>=20.0.0** installerat på din dator. Installera beroenden (npm install) och kör sedan projektet lokalt (npm run serve):

## Projektuppsättning
```
npm install
```

### Kompilerar och laddar om snabbt för utveckling
```
npm run serve
```

### Kompilerar och minifierar för produktion
```
npm run build
```

### Linter och fixar filer
```
npm run lint
```

### Anpassa konfigurationen
Se [Configuration Reference](https://cli.vuejs.org/config/).
