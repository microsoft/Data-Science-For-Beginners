# ഡേഞ്ചറസ് ലിയാസൺസ് ഡാറ്റാ വിഷ്വലൈസേഷൻ പ്രോജക്റ്റ്

ആരംഭിക്കാൻ, നിങ്ങളുടെ യന്ത്രത്തിൽ NPMയും Node **>=20.0.0** നും പ്രവർത്തിക്കുന്നതായി ഉറപ്പാക്കേണ്ടതാണ്. ആശ്രിതങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്യുക (npm install) പിന്നെ പ്രോജക്റ്റ് ലോക്കലായി പ്രവർത്തിപ്പിക്കുക (npm run serve):

## പ്രോജക്റ്റ് ക്രമീകരണം
```
npm install
```

### വികസനത്തിനായി കോംപൈൽ ചെയ്യുകയും ഹോട്ട്-റീലോഡ് നടത്തുകയും ചെയ്യുന്നു
```
npm run serve
```

### നിർമ്മാണത്തിനായി കോംപൈൽ ചെയ്ത് മിനിഫൈ ചെയ്യുന്നു
```
npm run build
```

### ഫയലുകൾ ലിൻറ് ചെയ്ത് ശരിയാക്കുന്നു
```
npm run lint
```

### ക്രമീകരണം ഇഷ്ടാനുസൃതമാക്കുക
കാണുക [Configuration Reference](https://cli.vuejs.org/config/).
