# ഡേഞ്ചറസ് ലിയാസൺസ് ഡാറ്റാ വിസ്വലൈസേഷൻ പ്രോജക്ട്

തുടങ്ങാൻ, നിങ്ങളുടെ മെഷീനിൽ NPM ഒപ്പം Node **>=20.0.0** പ്രവർത്തിക്കുകയാണെന്നു ഉറപ്പാക്കണം. ഉപയോഗിച്ചും (npm install) അനിവാര്യമായ ഡിപ്പൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്ത് തുടർന്ന് പ്രോജക്റ്റ് ലോക്കലി പ്രവർത്തിപ്പിക്കുക (npm run serve):

## പ്രോജക്ട് സെറ്റപ്പ്
```
npm install
```

### ഡവലപ്പ്മെന്റിനായി കമ്പൈൽ ചെയ്ത് ഹോട്ട്-റീലോഡ് ചെയ്യുന്നു
```
npm run serve
```

### പ്രൊഡക്ഷനായി കമ്പൈൽ ചെയ്ത് മിനിഫൈ ചെയ്യുന്നു
```
npm run build
```

### ലിന്റ് ചെയ്ത് ഫയലുകൾ തിരുത്തുന്നു
```
npm run lint
```

### ക്രമീകരണങ്ങൾ വ്യക്തിഗതമാക്കുക
[Configuration Reference](https://cli.vuejs.org/config/) നോക്കുക.
