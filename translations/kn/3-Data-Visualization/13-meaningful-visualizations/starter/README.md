# ಡೇಂಜರಸ್ ಲಿಯೀಜನ್ಸ್ ಡೇಟಾ ವಿಸುಯಲೈಜೆಶನ್ ಪ್ರಾಜೆಕ್ಟ್

ಪ್ರಾರಂಭಿಸಲು, ನಿಮ್ಮ ಯಂತ್ರದಲ್ಲಿ NPM ಮತ್ತು Node **>=20.0.0** ರನ್ ಆಗುತ್ತಿದೆ ಎಂದು ಖಾತ್ರಿಪಡಿಸಿಕೊಳ್ಳಬೇಕು. ಡಿಪೆಂಡೆನ್ಸಿಗಳನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ (npm install) ನಂತರ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ಸ್ಥಳೀಯವಾಗಿ ರನ್ ಮಾಡಿ (npm run serve):

## ಪ್ರಾಜೆಕ್ಟ್ ಸೆಟಪ್
```
npm install
```

### ಡೆವಲಪ್‌ಮೆಂಟ್‌ಗೆ ಸಂಕ್ಷಿಪ್ತವಾಗಿ ಸಂಯೋಜಿಸಿ ಮತ್ತು ಹಾಟ್ ರಿಲೋಡ್ ಮಾಡಿ
```
npm run serve
```

### ಉತ್ಪಾದನೆಗಾಗಿ ಸಂಯೋಜಿಸಿ ಮತ್ತು ಮಿನಿಫೈ ಮಾಡಿ
```
npm run build
```

### ಫೈಲ್‌ಗಳನ್ನು ಲಿಂಟ್ ಮಾಡಿ ಮತ್ತು ಸರಿಪಡಿಸಿ
```
npm run lint
```

### ಕಸ್ಟಮೈಸ್ ಕಾನ್ಫಿಗರೇಶನ್
ನೋಡಿ [Configuration Reference](https://cli.vuejs.org/config/).
