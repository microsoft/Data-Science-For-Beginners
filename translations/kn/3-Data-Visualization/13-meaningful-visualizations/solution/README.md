# ಡೇಂಜರಸ್ ಲಿಯೈಸನ್ಸ್ ಡೇಟಾ ದೃಶ್ಯೀಕರಣ ಪ್ರಾಜೆಕ್ಟ್

ಪ್ರಾರಂಭಿಸಲು, ನಿಮ್ಮ ಯಂತ್ರದಲ್ಲಿ NPM ಮತ್ತು Node **>=20.0.0** চলেುತ್ತಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಬೇಕಾಗುತ್ತದೆ. ಅವಶ್ಯಕತೆಯನ್ನು ಸ್ಥಾಪಿಸಿ (npm install) ನಂತರ ಪ್ರಾಜೆಕ್ಟ್ ಅನ್ನು ಸ್ಥಳೀಯವಾಗಿ ರನ್ ಮಾಡಿ (npm run serve):

## ಪ್ರಾಜೆಕ್ಟ್ ಸೆಟಪ್
```
npm install
```

### ಅಭಿವೃದ್ಧಿಗಾಗಿ ಸಂಯೋಜನೆ ಮತ್ತು ಹಾಟ್-ರಿಲೋಡ್
```
npm run serve
```

### ಉತ್ಪಾದನೆಗಾಗಿ ಸಂಯೋಜನೆ ಮತ್ತು ಕನಿಷ್ಠೀಕರಣ
```
npm run build
```

### ಲಿಂಟ್ ಮಾಡಿ ಮತ್ತು ಫೈಲಾಗಳನ್ನು ಸರಿಪಡಿಸಿ
```
npm run lint
```

### ಕಸ್ಟಮೈಸ್ ಕಾನ್ಫಿಗರೇಶನ್
[Configuration Reference](https://cli.vuejs.org/config/) ಅನ್ನು ನೋಡಿ.
