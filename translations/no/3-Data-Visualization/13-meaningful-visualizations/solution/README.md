# Dangerous Liaisons datavisualiseringsprosjekt

For å komme i gang må du sørge for at du har NPM og Node **>=20.0.0** som kjører på maskinen din. Installer avhengighetene (npm install) og kjør deretter prosjektet lokalt (npm run serve):

## Oppsett av prosjekt
```
npm install
```

### Kompilerer og hot-laster for utvikling
```
npm run serve
```

### Kompilerer og minifiserer for produksjon
```
npm run build
```

### Linter og fikser filer
```
npm run lint
```

### Tilpass konfigurasjonen
Se [Configuration Reference](https://cli.vuejs.org/config/).
