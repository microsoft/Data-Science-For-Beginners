# Dự án trực quan hóa dữ liệu Dangerous Liaisons

Để bắt đầu, bạn cần đảm bảo rằng bạn đã cài đặt NPM và Node **>=20.0.0** đang chạy trên máy của bạn. Cài đặt các phụ thuộc (npm install) và sau đó chạy dự án trên máy cục bộ (npm run serve):

## Thiết lập dự án
```
npm install
```

### Biên dịch và tải lại nhanh cho phát triển
```
npm run serve
```

### Biên dịch và rút gọn cho sản xuất
```
npm run build
```

### Kiểm tra và sửa lỗi tập tin
```
npm run lint
```

### Tùy chỉnh cấu hình
Xem [Tham khảo Cấu hình](https://cli.vuejs.org/config/).
