# Proyek visualisasi data Dangerous Liaisons

Untuk memulai, Anda perlu memastikan bahwa Anda memiliki NPM dan Node **>=20.0.0** yang berjalan di mesin Anda. Instal dependensi (npm install) dan kemudian jalankan proyek secara lokal (npm run serve):

## Pengaturan proyek
```
npm install
```

### Mengkompilasi dan menyegarkan secara hot untuk pengembangan
```
npm run serve
```

### Mengkompilasi dan meminifikasi untuk produksi
```
npm run build
```

### Melakukan lint dan memperbaiki file
```
npm run lint
```

### Menyesuaikan konfigurasi
Lihat [Configuration Reference](https://cli.vuejs.org/config/).
