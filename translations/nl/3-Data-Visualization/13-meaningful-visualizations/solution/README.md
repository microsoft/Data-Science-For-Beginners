# Dangerous Liaisons gegevensvisualisatieproject

Om te beginnen moet je ervoor zorgen dat je NPM en Node **>=20.0.0** op je machine hebt draaien. Installeer de dependencies (npm install) en start het project lokaal (npm run serve):

## Projectopzet
```
npm install
```

### Compileert en herlaadt snel voor ontwikkeling
```
npm run serve
```

### Compileert en minimaliseert voor productie
```
npm run build
```

### Lint en corrigeert bestanden
```
npm run lint
```

### Pas configuratie aan
Zie [Configuration Reference](https://cli.vuejs.org/config/).
