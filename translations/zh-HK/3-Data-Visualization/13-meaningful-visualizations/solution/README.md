# 危險關係資料視覺化專案

要開始，您需要確保您的機器上已執行 NPM 和 Node **>=20.0.0**。安裝相依套件（npm install），然後本地執行專案（npm run serve）：

## 專案設定
```
npm install
```

### 編譯並進行開發時即時熱重載
```
npm run serve
```

### 編譯並進行生產模式的壓縮
```
npm run build
```

### 檢查並修正程式碼格式
```
npm run lint
```

### 自訂配置
請參考 [Configuration Reference](https://cli.vuejs.org/config/)。
