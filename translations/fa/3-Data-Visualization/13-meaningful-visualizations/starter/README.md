# پروژه تجسم داده Dangerous Liaisons

برای شروع، باید اطمینان حاصل کنید که NPM و Node با نسخه **>=20.0.0** روی سیستم شما نصب و اجرا می‌شوند. وابستگی‌ها را نصب کنید (npm install) و سپس پروژه را به صورت محلی اجرا کنید (npm run serve):

## راه‌اندازی پروژه
```
npm install
```

### کامپایل و بارگذاری سریع برای توسعه
```
npm run serve
```

### کامپایل و فشرده‌سازی برای تولید
```
npm run build
```

### بررسی و اصلاح فایل‌ها
```
npm run lint
```

### تنظیمات سفارشی
به [مرجع پیکربندی](https://cli.vuejs.org/config/) مراجعه کنید.
