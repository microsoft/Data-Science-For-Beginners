# پروژه مصورسازی داده‌ها خطرناک

برای شروع، باید مطمئن شوید که نسخه NPM و Node **>=20.0.0** روی دستگاه شما نصب و اجرا می‌شود. وابستگی‌ها را نصب کنید (npm install) و سپس پروژه را به‌صورت محلی اجرا کنید (npm run serve):

## راه‌اندازی پروژه
```
npm install
```

### برای توسعه کامپایل و بارگذاری داغ انجام می‌دهد
```
npm run serve
```

### برای تولید نسخه بهینه و کوچک شده کامپایل می‌کند
```
npm run build
```

### فایل‌ها را بررسی و اصلاح می‌کند
```
npm run lint
```

### پیکربندی را شخصی‌سازی کنید
مشاهده [مرجع پیکربندی](https://cli.vuejs.org/config/).
