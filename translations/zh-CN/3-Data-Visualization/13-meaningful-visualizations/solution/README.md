# 危险关系数据可视化项目

要开始，请确保你的机器上运行了 NPM 和 Node **>=20.0.0**。安装依赖（npm install），然后本地运行项目（npm run serve）：

## 项目设置
```
npm install
```

### 编译并热重载以进行开发
```
npm run serve
```

### 编译并压缩以用于生产环境
```
npm run build
```

### 语法检查并修复文件
```
npm run lint
```

### 自定义配置
参见 [Configuration Reference](https://cli.vuejs.org/config/)。
