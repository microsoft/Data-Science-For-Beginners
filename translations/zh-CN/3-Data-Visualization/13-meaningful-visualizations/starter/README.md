# 《危险关系》数据可视化项目

要开始，请确保你的机器上运行着 NPM 和 Node **>=20.0.0**。安装依赖（npm install）然后本地运行项目（npm run serve）：

## 项目设置
```
npm install
```

### 为开发编译并热重载
```
npm run serve
```

### 为生产编译并压缩
```
npm run build
```

### 代码检查并修复文件
```
npm run lint
```

参见 [Configuration Reference](https://cli.vuejs.org/config/)。
