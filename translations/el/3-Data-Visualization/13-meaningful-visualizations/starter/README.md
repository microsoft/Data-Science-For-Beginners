# Έργο οπτικοποίησης δεδομένων Dangerous Liaisons

Για να ξεκινήσετε, πρέπει να βεβαιωθείτε ότι έχετε το NPM και το Node **>=20.0.0** να τρέχουν στον υπολογιστή σας. Εγκαταστήστε τις εξαρτήσεις (npm install) και μετά τρέξτε το έργο τοπικά (npm run serve):

## Ρύθμιση έργου
```
npm install
```

### Συγγράφει και πραγματοποιεί hot-reload για ανάπτυξη
```
npm run serve
```

### Συγγράφει και συμπιέζει για παραγωγή
```
npm run build
```

### Ελέγχει στυλ κώδικα και διορθώνει αρχεία
```
npm run lint
```

### Προσαρμογή ρυθμίσεων
Δείτε [Configuration Reference](https://cli.vuejs.org/config/).
