# Έργο οπτικοποίησης δεδομένων Dangerous Liaisons

Για να ξεκινήσετε, πρέπει να βεβαιωθείτε ότι έχετε εκτελέσει το NPM και το Node **>=20.0.0** στον υπολογιστή σας. Εγκαταστήστε τις εξαρτήσεις (npm install) και στη συνέχεια εκτελέστε το έργο τοπικά (npm run serve):

## Εγκατάσταση έργου
```
npm install
```

### Μεταγλωττίζει και φορτώνει ξανά ζεστά για ανάπτυξη
```
npm run serve
```

### Μεταγλωττίζει και συμπιέζει για παραγωγή
```
npm run build
```

### Ελέγχει και διορθώνει αρχεία
```
npm run lint
```

### Προσαρμογή διαμόρφωσης
Δείτε το [Configuration Reference](https://cli.vuejs.org/config/).
