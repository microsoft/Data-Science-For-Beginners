# Dangerous Liaisons डेटा व्हिज्युअलायझेशन प्रकल्प

सुरुवात करण्यासाठी, आपल्याकडे NPM आणि Node **>=20.0.0** आपल्या मशीनवर चालू आहे याची खात्री करा. अवलंबित्वे स्थापित करा (npm install) आणि नंतर प्रकल्प स्थानिकपणे चालवा (npm run serve):

## प्रकल्पाची स्थापना
```
npm install
```

### विकासासाठी संकलित करा आणि हॉट-रिलोड करा
```
npm run serve
```

### उत्पादनासाठी संकलित करा आणि संक्षिप्त करा
```
npm run build
```

### फाइल्स तपासा आणि दुरुस्त करा
```
npm run lint
```

### संरचना सानुकूल करा
पहा [Configuration Reference](https://cli.vuejs.org/config/).
