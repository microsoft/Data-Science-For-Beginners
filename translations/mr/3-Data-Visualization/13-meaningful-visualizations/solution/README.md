# Dangerous Liaisons डेटा व्हिज्युअलायझेशन प्रकल्प

सुरू करण्यासाठी, आपल्याकडे NPM आणि Node **>=20.0.0** आपल्या मशीनवर चालू असल्याची खात्री करा. अवलंबित्वे स्थापित करा (npm install) आणि नंतर प्रकल्प स्थानिकपणे चालवा (npm run serve):

## प्रकल्प सेटअप
```
npm install
```

### विकासासाठी संकलित करा आणि हॉट-रीलोड करा
```
npm run serve
```

### उत्पादनासाठी संकलित करा आणि मिनिफाय करा
```
npm run build
```

### फायली तपासा आणि दुरुस्त्या करा
```
npm run lint
```

### कॉन्फिगरेशन सानुकूलित करा
पहा [Configuration Reference](https://cli.vuejs.org/config/).
