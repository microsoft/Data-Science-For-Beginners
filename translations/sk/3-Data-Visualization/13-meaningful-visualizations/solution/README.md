# Projekt vizualizácie dát Nebezpečné vzťahy

Ak chcete začať, musíte mať na svojom počítači spustený NPM a Node **>=20.0.0**. Nainštalujte závislosti (npm install) a potom projekt spustite lokálne (npm run serve):

## Nastavenie projektu
```
npm install
```

### Kompiluje a automaticky obnovuje pre vývoj
```
npm run serve
```

### Kompiluje a minifikuje pre produkciu
```
npm run build
```

### Kontroluje a opravuje súbory
```
npm run lint
```

### Prispôsobenie konfigurácie
Pozrite si [Configuration Reference](https://cli.vuejs.org/config/).
