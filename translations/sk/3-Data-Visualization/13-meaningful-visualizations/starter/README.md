# Vizualizačný projekt Dangerous Liaisons

Na začiatok musíte mať na svojom počítači nainštalovaný NPM a Node **>=20.0.0**. Nainštalujte závislosti (npm install) a potom spustite projekt lokálne (npm run serve):

## Nastavenie projektu
```
npm install
```

### Kompiluje a automaticky obnovuje počas vývoja
```
npm run serve
```

### Kompiluje a minimalizuje pre produkciu
```
npm run build
```

### Kontroluje a opravuje súbory
```
npm run lint
```

### Prispôsobenie konfigurácie
Pozrite si [Konfiguračnú referenciu](https://cli.vuejs.org/config/).
