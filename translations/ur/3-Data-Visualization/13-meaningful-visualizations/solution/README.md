# خطرناک تعلقات ڈیٹا ویژولائزیشن پروجیکٹ

شروع کرنے کے لیے، آپ کو یہ یقینی بنانا ہوگا کہ آپ کے کمپیوٹر پر NPM اور Node **>=20.0.0** چل رہے ہیں۔ انحصاریوں کو انسٹال کریں (npm install) اور پھر پروجیکٹ کو لوکل طور پر چلائیں (npm run serve):

## پروجیکٹ سیٹ اپ
```
npm install
```

### ترقی کے لیے کمپائل اور ہاٹ ری لوڈ کریں
```
npm run serve
```

### پیداوار کے لیے کمپائل اور کم حجم کریں
```
npm run build
```

### فائلوں کی لینٹ اور اصلاح کریں
```
npm run lint
```

### ترتیب کو حسب ضرورت بنائیں
ملاحظہ کریں [Configuration Reference](https://cli.vuejs.org/config/)۔
