# Dangerous Liaisons adatvizualizációs projekt

A kezdéshez győződj meg róla, hogy a gépeden NPM és Node **>=20.0.0** fut. Telepítsd a függőségeket (npm install), majd futtasd a projektet helyileg (npm run serve):

## Projekt beállítása
```
npm install
```

### Fejlesztéshez fordítás és forró újratöltés
```
npm run serve
```

### Gyártásra fordítás és tömörítés
```
npm run build
```

### Fájlok lintelése és javítása
```
npm run lint
```

### Konfiguráció testreszabása
Lásd a [Configuration Reference](https://cli.vuejs.org/config/).
