# அபாயகரமான தொடர்புகள் தரவுத் திரைப்பிழை நெறித் திட்டம்

துவக்குவதற்கு, உங்கள் கணினியில் NPM மற்றும் Node **>=20.0.0** இயங்குகிறது என்பதை உறுதி செய்ய வேண்டும். சார்புகளை நிறுவவும் (npm install) பின்னர் இடதுசாரி திட்டத்தை இயக்கவும் (npm run serve):

## திட்ட அமைப்பு
```
npm install
```

### வெகுஜன வளர்ச்சிக்காக தொகுக்கவும், சூடான மறுசுழற்சி செய்யவும்
```
npm run serve
```

### உற்பத்திக்காக தொகுக்கவும், சுருக்கவும்
```
npm run build
```

### கோப்புகளை ஆராய்ந்து திருத்தவும்
```
npm run lint
```

### கட்டமைப்பை தனிப்பயனாக்கவும்
பார்க்கவும் [Configuration Reference](https://cli.vuejs.org/config/).
