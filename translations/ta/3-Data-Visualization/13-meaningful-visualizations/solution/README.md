# டேஞ்சரஸு லய்ட்சன்ஸ் தரவு காட்சிப்படுத்தும் திட்டம்

தொடங்க, உங்கள் மெயினில் NPM மற்றும் Node **>=20.0.0** இயங்குவதை உறுதிப்படுத்த வேண்டும். பொறுப்பீடுகளை நிறுவுங்கள் (npm install) பின்னர் திட்டத்தை உள்ளூர் இயங்க செய்யவும் (npm run serve):

## திட்ட அமைப்பு
```
npm install
```

### மேம்பாட்டுக்காக தொகுக்கும் மற்றும் சூடுபரிசீலனை செய்யும்
```
npm run serve
```

### வெளியீட்டுக்காக தொகுக்கும் மற்றும் சுருக்கப்படும்
```
npm run build
```

### கோப்புகளை சோதித்து திருத்துகிறது
```
npm run lint
```

### கட்டமைப்பை தனிப்பயன் செய்யவும்
[Configuration Reference](https://cli.vuejs.org/config/) ஐ பார்.
